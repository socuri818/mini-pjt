# 초보자용 풀마라톤 14주 훈련 계획 (영국심장재단 BHF)

## 이 계획의 대상
- BHF 안내 페이지는 초급(beginner) 계획이 "달리기 경험이 전혀 없거나 그 거리를 달려 본 적이 없는 새내기"에게 맞는다고 설명합니다.
- 계획은 14주(1주차~14주차) 구성이고, 마지막 14주차에 대회가 있습니다.

## 한 주의 구성 (주차에 따라 조금씩 다름)
- 월요일은 휴식이거나 요가·필라테스입니다.
- 화·목요일은 25~40분 정도의 이지(easy) 또는 스테디(steady) 러닝이고, 후반 주차에는 일부 60분 스테디도 있습니다.
- 수요일은 교차 훈련(cross-training)이거나 임계 강도(Threshold effort) 인터벌입니다. 3주차부터 "임계 강도 3×4분, 사이에 90초 조깅 회복" 같은 세션이 들어오고, 이후 4×4분, 4×5분, 4×6분으로 늘어납니다.
- 금요일은 대부분 휴식입니다.
- 토요일은 교차 훈련이거나 30분 안팎의 이지 러닝입니다.
- 일요일은 롱런입니다.

## 롱런 시간의 진행 (표기 단위는 거리가 아니라 시간)
| 주차 | 일요일 롱런 |
|---|---|
| 1주 | 75분 |
| 2주 | 80분 |
| 3주 | 90분 |
| 4주 | 105분 |
| 5주 | 120분 |
| 6주 | 120~140분 |
| 8주 | 150분 |
| 9주 | 150분 |
| 10주 | 마라톤 페이스 연습: 하프마라톤 대회에 나가거나 13마일을 마라톤 페이스로 달리고 15~20분 조깅·걷기로 마무리 |
| 11주 | 180분 (처음 120분은 이지, 마지막 60분은 목표 마라톤 페이스) |
| 12주 | 120분 (처음 90분은 이지, 마지막 30분은 목표 마라톤 페이스) |
| 13주 | 60분 (마지막 30분은 목표 마라톤 페이스) |
| 14주 | 대회 주간: 이지 러닝 30분, 20분, 15분 후 대회 |

- 표의 7주차 롱런은 PDF 표 추출이 불확실해 옮기지 않았습니다.
- 계획에서 가장 긴 롱런은 11주차의 180분(3시간)입니다. 14주 계획의 11주차이므로, 그 뒤 12~14주차가 감량·대회 주간입니다. (대회 주간 직전 3주 구간)
- 이 문서의 주차(1~14주)와 04번 테이퍼 문서의 "대회 N주 전" 표는 서로 다른 BHF 자료이며 기준 시점이 같다고 확인되지 않았습니다. 두 문서의 롱런 시점을 하나로 합쳐 말하지 않습니다.
- 롱런 중에는 필요하면 15~30분마다 5분씩 걸어도 된다고 안내합니다. (원문: "walk 5 mins every 15-30 mins if necessary")
- 마지막 3주(12~14주차)는 롱런 시간과 평일 러닝이 눈에 띄게 줄어드는 구간으로, 테이퍼링과 겹칩니다. (04번 문서 참고)

## 한계
- 영국 자선단체가 제공하는 일반 계획이며, 개인의 현재 체력이나 부상 이력은 반영하지 않습니다.
- 롱런을 거리(km)가 아닌 시간으로만 표기하므로, km 단위 기준은 이 문서에서 알 수 없습니다.
- PDF 표가 복잡해 주차별 세부 칸 일부는 위에 옮기지 않았습니다.
